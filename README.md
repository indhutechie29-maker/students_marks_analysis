# 🎓 Student Marks Analysis Dashboard

## 📌 Project Overview

The Student Marks Analysis project focuses on analyzing students' academic performance using Python, Pandas, MySQL, and data visualization techniques.

This project helps to understand student performance, subject-wise marks, pass and fail percentages, student rankings, and marks distribution through an interactive dashboard developed using Streamlit and Plotly.

## 🎯 Project Objectives

- Analyze students' academic performance.
- Calculate subject-wise average marks.
- Identify top-performing students.
- Analyze pass and fail percentages.
- Perform marks range analysis.
- Identify students who need academic improvement.
- Build an interactive student performance dashboard.

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/indhutechie29-maker/students_marks_analysis.git
```

### Step 2: Open the Project Folder

```bash
cd students_marks_analysis
```

### Step 3: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 4: Run the Dashboard

```bash
streamlit run app.py
```

### Step 5: Open in Browser

```text
http://localhost:8501
```
