Student Marks Analysis Using Python and SQL

Project Overview

This project analyzes student marks using Python, Pandas, and MySQL to understand academic performance, subject-wise averages, pass/fail results, and student rankings.

Tools Used

- Python
- Pandas
- MySQL
- MySQL Workbench
- GitHub

Project Objectives

- Calculate the average marks for each subject.
- Identify students who passed or failed.
- Find the top-performing students.
- Analyze subject-wise pass and fail counts.
- Calculate class averages.
- Identify students performing above the class average.
- Categorize marks into ranges for performance analysis.

Files Included

- "students_analysis.py" — Python code for analyzing student marks.
- "students_marks_analysis.sql" — SQL queries for analyzing student marks.

Key Skills Demonstrated

- Data cleaning and handling missing values
- Data analysis using Python and Pandas
- SQL queries and aggregate functions
- Filtering, sorting, and ranking data
- Extracting insights from student performance data

How to Use

1. Download or clone this repository.
2. Open the SQL file in MySQL Workbench.
3. Import your student marks dataset into a MySQL table named "students_marks".
4. Run the SQL queries to analyze the data.
5. Run the Python script in an environment with Pandas installed.
